# LibmemCli v1.0.0

> Historical release before the Libmem.NET identity migration. Asset and assembly names remain `LibmemCli`; this archive does not describe current main or authorize republication.

LibmemCli v1.0.0 is the first stable **Windows x64 / .NET 8** release of the reusable C++/CLI wrapper around the pinned rdbo/libmem native library.

## Highlights

- Stable `ProcessSession` + Manager API for process-scoped operations
- Process, thread, module, memory, scan, symbol, assembly/disassembly, Hook/VMT, and DLL injection support
- Deterministic ownership through `RemoteAllocation`, `HookHandle`, `VmtManager`, and `InjectedModuleHandle`
- Frozen v1.0 public managed contract with CI-enforced API baseline
- Explicit null / sentinel / exception behavior
- PID + process start-time identity checks where process identity matters
- Runtime validation for Hook/VMT, injection, external-process memory operations, and consumer packaging
- Formal Windows x64 runtime package with manifest and SHA-256 verification

## Platform

- **OS:** Windows
- **Architecture:** x64
- **Managed runtime:** .NET 8
- **Native backend:** pinned rdbo/libmem
- **x86:** deferred; no official v1.0.0 x86 asset
- **NuGet:** local/CI prototype only; not an official v1.0.0 distribution channel
