# Libmem.NET 2.2.1 — Release Notes / 发布说明

> Stable release published on GitHub and nuget.org on 2026-10-08. Release commit: `5e2b051a61943d0ac0825b2ac0125ffb29cf1721`.
>
> 稳定版已于 2026-10-08 发布到 GitHub 和 nuget.org，发布提交为上述 commit。

## English

**Libmem.NET 2.2.1** is a backward-compatible stability and delivery-safety patch for **Windows x64/x86 and .NET 8**. It does not change the managed Public API, the pinned rdbo/libmem revision, or the x64/x86 package layout.

### Fixes and improvements

- **Release safety:** Serialize concurrent Release executions for the same ref without canceling an in-flight publish; retain duplicate package push safeguards.
- **Diagnostics:** Allow manual Hook/VMT and Injector workflows to target either x64 or x86.
- **DLL injection:** Report a DLL that exists but cannot be loaded as `LM_LoadModuleEx` failure, rather than misclassifying it as module enumeration failure.
- **Scanning boundaries:** Recover the final legal DataScan, PatternScan, and SigScan candidate, including exact-size windows; reject ranges that overflow the address width.
- **NuGet architecture selection:** An explicitly set `PlatformTarget` must be `x64` or `x86`. Reject `AnyCPU`, `arm64`, and other unsupported explicit values even if `Platform` selects x64/x86. Fall back to `Platform` only when `PlatformTarget` is empty, retaining `Win32` → `x86` mapping.

### Compatibility and delivery

Supported: Windows x64/x86, .NET 8, architecture-matched C++/CLI and native assets. Unsupported: AnyCPU, ARM64, and cross-bitness operation. Existing supported consumers need no source-level API migration.

Consume `Libmem.NET` version `2.2.1` from nuget.org or the [GitHub Release](https://github.com/CardResearchLab/Libmem.NET/releases/tag/v2.2.1). The exact-version x64/x86 runtime ZIPs, checksums, and multi-architecture NuGet package were validated against the release commit.

## 简体中文

**Libmem.NET 2.2.1** 是面向 **Windows x64/x86 与 .NET 8** 的兼容性稳定修复版本，同时增强发布过程的安全性。不修改托管 Public API、固定的 rdbo/libmem 版本，也不改变 x64/x86 包结构。

### 修复与改进

- **发布安全：** 同一 Git 引用上的 Release 工作流串行执行，不会取消正在发布的任务；保留 NuGet 重复包防护。
- **诊断能力：** 手动 Hook/VMT、Injector 工作流均可选择 x64 或 x86 架构。
- **DLL 注入：** 文件存在但无法加载时，正确报告为 `LM_LoadModuleEx` 失败，不再错误归类为模块枚举失败。
- **扫描边界：** 修复 DataScan、PatternScan、SigScan 在扫描窗口最后一个合法位置可能漏检的问题，覆盖恰好等长的扫描窗口，并拒绝地址位宽溢出的范围。
- **NuGet 架构选择：** 显式指定的 `PlatformTarget` 只能是 `x64` 或 `x86`；即使 `Platform` 是有效架构，也会拒绝 `AnyCPU`、`arm64` 等不支持的值。仅在 `PlatformTarget` 为空时回退到 `Platform`，保留 `Win32` → `x86` 映射。

### 兼容性与交付

正式支持 Windows x64/x86、.NET 8，以及架构匹配的 C++/CLI 与原生组件。不支持 AnyCPU、ARM64 和跨位宽操作。现有受支持的消费者不需要迁移 Public API。

现在可从 nuget.org 获取 `Libmem.NET 2.2.1`，或通过 [GitHub Release](https://github.com/CardResearchLab/Libmem.NET/releases/tag/v2.2.1) 下载。正式发布流程已验证同一提交的 x64/x86 Runtime ZIP、校验文件及双架构 NuGet 包。
